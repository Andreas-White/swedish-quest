# Helper verbs: vill, kan, måste, ska

Helper verbs team up with a second verb. The helper carries the meaning; the second verb stays in the infinitive.

- `vill` (want)
- `kan` (can)
- `måste` (must)
- `ska` (shall / will)

Order: subject + helper + infinitive.

- `Jag vill tala svenska.` (I want to speak Swedish.)
- `Du kan stanna här.` (You can stay here.)
- `Vi måste jobba idag.` (We must work today.)
- `Han ska fråga Anna.` (He will ask Anna.)

## No "att" in the middle

In English we say "want *to* speak". In Swedish, no `att` after these four helpers.

- `Jag vill tala.` (I want to speak.)
- `Hon kan bo här.` (She can live here.)
- `De ska kalla Erik.` (They will call Erik.)

The infinitive is the plain form: `tala`, `bo`, `stanna`, `fråga`.

## Pick the right helper

- `vill` = wish: `Jag vill prata.` (I want to talk.)
- `kan` = ability: `Jag kan prata.` (I can talk.)
- `måste` = need: `Jag måste prata.` (I must talk.)
- `ska` = plan: `Jag ska prata.` (I will talk.)

Compare:

- `Jag vill jobba.` (I want to work.)
- `Jag måste jobba.` (I must work.)

## Common mistakes

- ✗ `Jag vill talar.` → ✓ `Jag vill tala.` (After a helper, infinitive.)
- ✗ `Jag vill att tala.` → ✓ `Jag vill tala.` (No `att` after `vill`.)
- ✗ `Vill jag tala.` → ✓ `Jag vill tala.` (Subject first, then helper.)

## Summary

- Pattern: `Jag vill tala.` `Du kan bo här.`
- Helpers: `vill`, `kan`, `måste`, `ska`.
- Main verb stays in the infinitive.
