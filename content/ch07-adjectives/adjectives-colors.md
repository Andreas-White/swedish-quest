# Adjectives Colors

Colors are adjectives, so they change to match the noun. Learn the six basic colors and the `en`/`ett` endings.

- `En röd bil.` / `Ett rött hus.`

## Six colors

- `röd` = red
- `blå` = blue
- `grön` = green
- `gul` = yellow
- `svart` = black
- `vit` = white

## En-words vs ett-words

`en` words use the base form. `ett` words usually add `-t`.

- `En röd bil.` / `Ett rött hus.`
- `En blå bil.` / `Ett blått hus.`
- `En grön bil.` / `Ett grönt hus.`
- `En gul bil.` / `Ett gult hus.`
- `En svart bil.` / `Ett svart hus.`
- `En vit bil.` / `Ett vitt hus.`

Note `blått`, `grönt`, `gult` and `vitt` double or add `-t`. `svart` stays the same.

## After är

After `är`, the color still matches the subject.

- `Bilen är röd.`
- `Huset är rött.`
- `Bilen är svart.` / `Huset är svart.`

## Common mistakes

- ✗ `Ett röd hus.` → ✓ `Ett rött hus.` (`ett` words need the `-t` form.)
- ✗ `En vitt bil.` → ✓ `En vit bil.` (`en` words use the base form.)
- ✗ `Huset är röd.` → ✓ `Huset är rött.` (Match after `är` too.)

## Summary

- Six colors: `röd`, `blå`, `grön`, `gul`, `svart`, `vit`.
- `En röd bil.` but `Ett rött hus.`
- `svart` never changes; most others add `-t` for `ett`.
- Colors match after `är` as well.
