# Preteritum verbs

Three groups cover most past verbs: -ar → -ade, -er → -de/-te, and short irregulars you learn by heart.

## Group 1: tala → talade

Verbs ending in -ar add -ade.

- `Jag talar.` → `Jag talade.` (I speak → I spoke.)
- `Vi handlar.` → `Vi handlade.` (We shop → We shopped.)
- `Hon stannar.` → `Hon stannade.` (She stays → She stayed.)

## Group 2: läsa → läste, bo → bodde

Many -er verbs add -de or -te. Learn each one: `läsa` → `läste`, `köpa` → `köpte`, `bo` → `bodde`, `ha` → `hade`, `göra` → `gjorde`.

- `Jag läser.` → `Jag läste.` (I read → I read.)
- `Vi bor här.` → `Vi bodde här.` (We live → We lived.)
- `Hon köper bröd.` → `Hon köpte bröd.` (She buys → She bought.)
- `Jag har tid.` → `Jag hade tid.` (I have → I had.)
- `De gör mat.` → `De gjorde mat.` (They make → They made.)

## Group 3: short verbs

These change the vowel. Learn them as pairs.

- `äta` → `åt` (eat → ate)
- `dricka` → `drack` (drink → drank)
- `gå` → `gick` (go → went)
- `komma` → `kom` (come → came)
- `sova` → `sov` (sleep → slept)
- `vara` → `var` (am/is → was)
- `skriva` → `skrev` (write → wrote)

Sentences: `Jag åt frukost.` `Vi drack kaffe.` `Hon gick hem.` `De kom igår.`

## Common mistakes

- ✗ `Jag talde.` → ✓ `Jag talade.` (-ar verbs add -ade, not -de.)
- ✗ `Vi bodde här bor.` → ✓ `Vi bodde här.` (One verb — bodde already marks past.)
- ✗ `Hon gådde hem.` → ✓ `Hon gick hem.` (Gå is irregular: gick.)

## Summary

- -ar → -ade: `talade`, `handlade`.
- -er → -de/-te: `läste`, `köpte`, `bodde`, `hade`, `gjorde`.
- Short verbs: `åt`, `drack`, `gick`, `kom`, `sov`, `var`, `skrev`.
