# Formal Swedish

Swedes speak one way and write another. Speech (talspråk) uses `dom` and short forms; writing (skriftspråk) uses `de`, `dem` and fuller sentences.

- Spoken: `Dom kommer snart.`
- Written: `De kommer snart.`

## Spoken vs written

In speech you will hear shortened, casual forms. In writing, use the full standard forms.

- Spoken `dom` → written `de` or `dem`
- Spoken `nåt` → written `något`
- Spoken `sen` → written `sedan`
- Spoken `ska` stays `ska`, but write full sentences around it

Example pair: `Dom ska komma sen.` becomes `De ska komma sedan.`

## de and dem

`dom` (spoken "they/them") splits into two written words:

- `de` = they (subject): `De bor här.`
- `dem` = them (object): `Jag ser dem.`
- `De hjälper dem.`
- `Ge boken till dem.`

Tip: if English says "they", write `de`. If English says "them", write `dem`.

## Skriftlig svenska

Written Swedish (skriftlig svenska) prefers complete sentences, capital letters, and no slang.

- `Hej, jag skriver angående mötet.`
- `Tack för ditt svar.`
- `Med vänlig hälsning, Anna.`

Avoid chat forms like `hejhej`, `asså`, and `typ` in writing.

## Common mistakes

- ✗ `Dom bor här.` → ✓ `De bor här.` (Write `de` for "they".)
- ✗ `Jag ser dom.` → ✓ `Jag ser dem.` (Write `dem` for "them".)
- ✗ `Jag vill ha nåt sen.` → ✓ `Jag vill ha något sedan.` (Use full written forms.)

## Summary

- Speech uses `dom`, `nåt`, `sen`; writing uses `de/dem`, `något`, `sedan`.
- `de` = they, `dem` = them.
- Written Swedish uses full sentences and standard spelling.
- Save slang for speech, not for applications or emails.
