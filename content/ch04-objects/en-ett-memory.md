# En and ett memory tricks

Swedish nouns come in two genders. The word for "a" tells you which: `en` or `ett`.

- `en bok` (a book)
- `en bil` (a car)
- `ett hus` (a house)
- `ett äpple` (an apple)

Gender changes how plurals and "the" forms work later. Learn it now with the noun.

## Trick 1: guess en

About three in four nouns are en-words. If you must guess, guess `en`.

- `en flicka` (a girl)
- `en tidning` (a newspaper)
- `en smörgås` (a sandwich)
- `en kaffe` (a coffee)

## Trick 2: words ending in -a are usually en

Nouns ending in `a` are almost always en-words.

- `en flicka`
- `en klocka` (a clock)
- `en kvinna` (a woman)

Say the ending aloud. If it ends in "a", write `en`.

## Trick 3: there is no trick for ett — learn it

Ett-words have no safe rule. Learn them as chunks.

- `ett hus`
- `ett barn` (a child)
- `ett äpple`
- `ett brev` (a letter)

Study tip: never learn `hus` alone. Always learn `ett hus`. Flashcards should show `en bok` and `ett hus`, never just the noun.

## Common mistakes

- ✗ `ett bok` → ✓ `en bok.` (Learn `bok` as an en-word.)
- ✗ `en hus` → ✓ `ett hus.` (`Hus` is an ett-word.)
- ✗ `en äpple` → ✓ `ett äpple.` (`Äpple` is an ett-word.)

## Summary

- Default guess: `en`.
- Ends in `a` → almost always `en`.
- `ett` words must be memorised: `ett hus`, `ett barn`.
- Always learn article + noun together.
