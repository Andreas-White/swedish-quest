# Using the passive

Swedish uses the passive more than English does — on signs, in recipes, in news. If **who** acts matters less than **what** happens, choose the passive.

- `Bilen tvättas varje vecka.`
- `Det görs av personalen.`

## When to use the passive

Use it when the actor is unknown, obvious, or unimportant.

- Routines: `Gatan städas varje morgon.`
- Signs and rules: `Biljetter säljs här.`
- Processes: `Maten lagas från klockan elva.`
- News style: `Beslutet fattas imorgon.`

If you would start with "one / people in general", Swedish prefers the passive.

## Det görs…

`Det` + passive is a handy frame for general statements.

- `Det görs här.`
- `Det sägs att det blir regn.`
- `Det serveras kaffe efter mötet.`
- `Det byggs många hus nu.`

You do not need to say who does it.

## The av-phrase

When you do name the actor, add `av` (by) + the actor.

- `Bilen tvättas av mig.`
- `Huset byggdes av min farfar.` (past example to recognise)
- `Maten lagas av kocken.`
- `Beslutet fattas av chefen.`

Most everyday passives skip the `av`-phrase. Add it only when the "by whom" is news.

## Common mistakes

- ✗ `Bilen tvättar varje vecka.` → ✓ `Bilen tvättas varje vecka.` (Routine with no actor takes the passive.)
- ✗ `Maten lagas från kocken.` → ✓ `Maten lagas av kocken.` (The agent uses `av`, not `från`.)
- ✗ `Det görs av man gör det här.` → ✓ `Det görs här.` (Do not double the actor.)

## Summary

- Use the passive for routines, signs, and processes.
- `Det` + passive frames general claims: `Det sägs att….`
- Name the actor with `av`: `lagas av kocken.`
- Skip the `av`-phrase unless the actor is news.
