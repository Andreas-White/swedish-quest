# Being polite

A few small words make Swedish requests sound kind. Add them at the start or end.

- `Ursäkta, var är toaletten?`
- `Tack så mycket!`

## Core polite words

- `ursäkta` (excuse me): `Ursäkta, kan du hjälpa mig?`
- `tack` (thanks): `Tack för hjälpen!`
- `varsågod` (here you go / you are welcome): `Varsågod och sitt!`
- `förlåt` (sorry): `Förlåt, jag förstår inte.`

## Softening with skulle kunna

`Skulle jag kunna få` + noun is softer than `Kan jag få`.

- `Kan jag få kaffe?` (direct)
- `Skulle jag kunna få kaffe?` (softer)
- `Skulle du kunna hjälpa mig?`
- `Skulle det gå bra imorgon?`

## Common mistakes

- ✗ `Ge mig kaffe!` (to a stranger) → ✓ `Skulle jag kunna få kaffe?` (Soften requests to strangers.)
- ✗ `Tack!` (when handing something over) → ✓ `Varsågod!` (`Tack` is for receiving.)
- ✗ `Ursäkta!` (after stepping on a foot) → ✓ `Förlåt!` (`Förlåt` apologises; `ursäkta` gets attention.)

## Summary

- Get attention with `Ursäkta`, apologise with `Förlåt`.
- Give with `Varsågod`, receive with `Tack`.
- Soften requests with `Skulle jag kunna få`.
