# Reflexive sig

When the subject and the object are the same person, Swedish uses a reflexive word. For `han`, `hon` and `de` it is `sig`.

- `Han tvättar sig.`
- `Hon lär sig svenska.`
- `De sätter sig ner.`

## Sig for third person only

First and second persons reuse `mig`, `dig`, `oss` and `er`. Only third person gets the special word `sig`.

- `Jag tvättar mig.`
- `Du tvättar dig.`
- `Han tvättar sig.`
- `Vi sätter oss ner.`
- `Sätt er här!`

## Common reflexive verbs

Some verbs almost always appear with `sig`.

- `sätta sig` (to sit down): `Vi sätter oss här.`
- `lära sig` (to learn): `Hon lär sig svenska.`
- `trivas` (to thrive, feel at home): `Jag trivs i Sverige.`
- `Trivs du på jobbet?`
- `De trivs mycket bra här.`

## Emphasis with själv

Add `själv` to stress “by oneself”.

- `Hon tvättar sig själv.`
- `Han lagar maten själv.`
- `Ta hand om dig själv!`

## Common mistakes

- ✗ `Han tvättar honom.` → ✓ `Han tvättar sig.` (`honom` means someone else.)
- ✗ `Jag tvättar sig.` → ✓ `Jag tvättar mig.` (`sig` is only third person.)
- ✗ `De lär dem svenska.` → ✓ `De lär sig svenska.` (`dem` means other people.)

## Summary

- Third person reflexive is `sig`: `Han tvättar sig.`
- First and second persons use `mig`, `dig`, `oss`, `er`.
- Learn `sätta sig`, `lära sig` and `trivas` as whole chunks.
