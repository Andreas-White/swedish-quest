# Past tense

Swedish **preteritum** (simple past) talks about finished actions: `äter` → `åt` (ate), `läser` → `läste` (read).

## Present vs past

- `Jag äter.` → `Jag åt.` (I eat → I ate.)
- `Hon läser.` → `Hon läste.` (She reads → She read.)
- `Vi dricker kaffe.` → `Vi drack kaffe.` (We drink → We drank.)
- `De går hem.` → `De gick hem.` (They go → They went.)

The subject stays the same. Only the verb changes.

## Two easy patterns

Regular -ar verbs add -ade: `tala` → `talade`. Many -er verbs add -de or -te: `läsa` → `läste`.

- `Jag talar svenska.` → `Jag talade svenska.` (I speak → I spoke.)
- `Han köper bröd.` → `Han köpte bröd.` (He buys → He bought.)
- `Vi bor här.` → `Vi bodde här.` (We live → We lived.)

Some short verbs change the vowel: `äta` → `åt`, `dricka` → `drack`, `gå` → `gick`.

## Common mistakes

- ✗ `Jag ätade.` → ✓ `Jag åt.` (Äta is irregular: åt.)
- ✗ `Hon läste igår läser.` → ✓ `Hon läste igår.` (One verb per clause — läste already marks past.)
- ✗ `Vi gick hem igår går.` → ✓ `Vi gick hem igår.` (Do not add present går after past gick.)

## Summary

- Present `äter` → past `åt`. Present `läser` → past `läste`.
- `tala` → `talade`. `köpa` → `köpte`. `bo` → `bodde`.
- Short verbs: `gå` → `gick`, `dricka` → `drack`.
