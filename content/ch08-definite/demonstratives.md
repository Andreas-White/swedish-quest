# Pointing with den här

To say this or that, use `den här` (common), `det här` (neuter) or `de här` (plural). The noun takes its definite form.

- `den här boken` (this book)
- `det här huset` (this house)
- `de här böckerna` (these books)

## This: near you

Pick the pointer that matches the noun, then use the definite noun.

- `den här bilen` (this car)
- `det här äpplet` (this apple)
- `de här bilarna` (these cars)

Full sentences work the same way.

- `Den här boken är bra.`
- `Det här huset är stort.`

## That: den där

Use `den där`, `det där` and `de där` for things farther away.

- `den där bilen` (that car)
- `det där huset` (that house)
- `de där böckerna` (those books)

## Common mistakes

- ✗ `den här bok` → ✓ `den här boken.` (The pointer needs the definite noun.)
- ✗ `det här boken` → ✓ `den här boken.` (`bok` is an `en` word, so use `den här`.)
- ✗ `de här bilen` → ✓ `de här bilarna.` (Plural pointer needs the plural definite noun.)

## Summary

- `den här` + common definite: `den här boken`.
- `det här` + neuter definite: `det här huset`.
- `de här` + plural definite: `de här böckerna`.
- Distance uses `där`: `den där bilen`.
