# Build questions

Questions reuse the same tiles as statements, in a new order. Yes/no questions start with the verb. Question-word questions start with the question word.

- `Du äter.` → `Äter du?`
- `Du bor här.` → `Var bor du?`

## Yes/no questions

Put the verb first and the subject second. Add `inte` after the subject to ask a negative question.

- `Äter du?`
- `Läser hon?`
- `Äter du inte?`
- `Bor ni här?`

## Question-word questions

Start with `vad`, `var`, `vem`, `när`, `varför` or `hur`. Then verb, then subject.

- `Vad äter du?`
- `Var bor hon?`
- `Vem kommer idag?`
- `När äter vi?`

## Inte in questions

`inte` goes after the subject in questions, because the verb and subject both moved forward.

- Statement: `Du äter inte.`
- Question: `Äter du inte?`
- Statement: `Hon läser inte.` → `Läser hon inte?`

With a question word, `inte` still sits after the subject.

- `Varför äter du inte?`
- `Vad läser hon inte?`

## Common mistakes

- ✗ `Du äter?` → ✓ `Äter du?` (Questions start with the verb.)
- ✗ `Vad du äter?` → ✓ `Vad äter du?` (The verb follows the question word.)
- ✗ `Äter inte du?` → ✓ `Äter du inte?` (`inte` comes after the subject in questions.)

## Summary

- Yes/no: verb + subject: `Äter du?`
- Question word + verb + subject: `Var bor du?`
- In questions `inte` follows the subject: `Äter du inte?`
- Same tiles, new order — nothing else changes.
