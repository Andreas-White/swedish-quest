# Build present-tense statements

A Swedish statement needs three tiles: **who + action + rest**. Start with the subject, add the present-tense verb, then the rest.

- `Hon läser.` (who + action)
- `Hon läser en bok.` (who + action + rest)

## Statements: subject + verb

The subject goes first, the verb second. The verb never changes per person.

- `Jag äter.` `Du äter.` `Han äter.`
- `Vi läser.` `De bor här.`

Add an object or place at the end.

- `Hon läser en bok.`
- `Vi äter frukost.`
- `De bor här.`

## Time first: move the subject after the verb

Starting with `idag` or `imorgon` keeps the verb second, so the subject slides to third place.

- `Jag äter.` → `Idag äter jag.`
- `Han kommer.` → `Imorgon kommer han.`
- `Vi läser.` → `Nu läser vi.`

## Yes/no questions: verb first

Flip the first two tiles to make a question. Nothing else changes.

- `Du äter.` → `Äter du?`
- `Hon läser.` → `Läser hon?`
- `Du har en bil.` → `Har du en bil?`

## Common mistakes

- ✗ `Hon läsa en bok.` → ✓ `Hon läser en bok.` (Statements need the present form.)
- ✗ `Idag jag äter.` → ✓ `Idag äter jag.` (Time first pushes the subject after the verb.)
- ✗ `Du äter?` → ✓ `Äter du?` (Questions start with the verb.)

## Summary

- Statements: subject + present verb + rest.
- Time first: verb stays second, subject moves third.
- Yes/no questions: verb + subject.
- The present verb never changes per person.
