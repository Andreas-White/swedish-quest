# Infinitive clinic

The **infinitive** is the dictionary form: `äta`, `tala`, `läsa`. The word `att` means "to" before a verb.

- `att äta` (to eat)
- `att tala` (to speak)
- `att läsa` (to read)

Use `att` when the infinitive is the second idea in the sentence.

- `Jag vill lära mig att läsa.` (I want to learn to read.)
- `Det är roligt att tala svenska.` (It is fun to speak Swedish.)

## After vill, kan, måste, ska: no att

Helper verbs drop `att`.

- `Jag vill äta.` (I want to eat.)
- `Du kan läsa.` (You can read.)
- `Vi måste sova.` (We must sleep.)
- `Han ska köpa mjölk.` (He will buy milk.)

Think: helper + bare infinitive. Nothing between them.

## After tycka om att and many phrases: keep att

Feelings and opinions about activities keep `att`.

- `Jag tycker om att läsa.` (I like reading / to read.)
- `Jag älskar att dricka kaffe.` (I love drinking coffee.)
- `Jag försöker att sova.` (I try to sleep.)

Pattern: `tycker om att` + infinitive.

## Common mistakes

- ✗ `Jag vill att äta.` → ✓ `Jag vill äta.` (No `att` after `vill`.)
- ✗ `Jag tycker om läsa.` → ✓ `Jag tycker om att läsa.` (`Tycka om` needs `att`.)
- ✗ `Jag vill äter.` → ✓ `Jag vill äta.` (After `vill`, infinitive.)

## Summary

- `att` + infinitive = "to eat": `att äta`.
- `vill`, `kan`, `måste`, `ska` drop `att`.
- `tycker om att` keeps `att`.
