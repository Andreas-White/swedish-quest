# Word order in subordinate clauses

Swedish has one famous word-order rule for subordinate clauses: the **BIFF rule** — "bisats, inte före verbet" (in a bisats, `inte` comes before the verb).

- Main: `Han äter inte.`
- Subordinate: `att han inte äter.`

## The BIFF rule

In a main clause, `inte` comes **after** the verb. In a subordinate clause, it moves **before** the verb.

- `Han kommer.` → `Jag tror att han inte kommer.`
- `Hon äter kött.` → `Jag vet att hon inte äter kött.`
- `De sover.` → `Hon säger att de inte sover.`
- `Vi har tid.` → `Han hoppas att vi inte har bråttom.`

Compare side by side: `Han äter inte.` but `att han inte äter.`

## No inversion in a bisats

Main clauses invert after a time word: `Imorgon kommer han.` In a bisats the order stays subject → verb, never inverted.

- `Imorgon kommer han.` (main, inverted)
- `Jag vet att han kommer imorgon.` (bisats, straight order)
- `Eftersom hon jobbar idag.` (straight order, no inversion)
- `Om du har tid.` (straight order, no inversion)

Even if the bisats starts with `när` or `eftersom`, the subject still comes first.

## Full examples

Put both rules together: straight order + `inte` before the verb.

- `Jag tror att han inte kommer idag.`
- `Hon säger att hon inte hinner.`
- `Vi vet att de inte bor här.`
- `Ring när du inte kör bil.`

## Common mistakes

- ✗ `Jag tror att han äter inte.` → ✓ `Jag tror att han inte äter.` (`inte` before the verb in a bisats.)
- ✗ `Jag vet att kommer han imorgon.` → ✓ `Jag vet att han kommer imorgon.` (No inversion in a bisats.)
- ✗ `Eftersom jobbar hon idag.` → ✓ `Eftersom hon jobbar idag.` (Subject first in a bisats.)

## Summary

- BIFF: in a bisats, `inte` goes before the verb.
- A bisats keeps straight order — no inversion.
- Main: `Han äter inte.` Subordinate: `att han inte äter.`
- Applies after `att`, `som`, `eftersom`, `när`, `om` and `medan`.
