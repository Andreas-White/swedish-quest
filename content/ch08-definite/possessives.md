# Possessives

Possessives say who owns something. `min`, `din` and similar words change for `en` words, `ett` words and plurals. `hans` and `hennes` never change.

- `min bil` / `mitt hus` / `mina böcker`

## Min and din

Match the form to the thing owned, not to the owner.

- `min bil` (`en` word)
- `mitt hus` (`ett` word)
- `mina böcker` (plural)
- `din bil` / `ditt hus` / `dina böcker`

Full sentences:

- `Min bil är röd.`
- `Mitt hus är stort.`
- `Mina böcker är bra.`

## Hans and hennes never change

`hans` (his) and `hennes` (her/hers) keep one form for everything.

- `hans bil` / `hans hus` / `hans böcker`
- `hennes bil` / `hennes hus` / `hennes böcker`
- `Hans bil är svart.`
- `Hennes hus är vitt.`

## Common mistakes

- ✗ `mitt bil` → ✓ `min bil.` (`bil` is an `en` word, so use `min`.)
- ✗ `min hus` → ✓ `mitt hus.` (`hus` is an `ett` word, so use `mitt`.)
- ✗ `hennesa böcker` → ✓ `hennes böcker.` (`hennes` never changes.)

## Summary

- `min` / `mitt` / `mina` match the thing owned.
- Same pattern for `din` / `ditt` / `dina`.
- `hans` and `hennes` have one form each.
- Match `en`, `ett` and plural every time.
