# Build with helpers

Helper verbs like `vill` (want), `kan` (can) and `måste` (must) let you build longer sentences. The helper takes second place and the main verb switches to the **infinitive**.

- `Jag vill läsa.`
- `Hon kan simma.`
- `Vi måste äta.`

## Helper + infinitive

The pattern is subject + helper + infinitive. The infinitive is the dictionary form ending in `-a`.

- `äta` → `Jag vill äta.`
- `läsa` → `Han kan läsa.`
- `sova` → `De måste sova.`

The helper carries the time. Only the helper looks like a present verb.

## Add an object

Put the object after the infinitive to finish the sentence.

- `Jag vill läsa en bok.`
- `Han kan laga mat.`
- `Hon måste dricka vatten.`
- `Vi vill köpa en bil.`

## Helpers follow V2 too

With `idag` first, the helper stays second and the subject moves third. The infinitive stays put.

- `Jag vill läsa.` → `Idag vill jag läsa.`
- `Hon kan simma.` → `Imorgon kan hon simma.`

## Common mistakes

- ✗ `Jag vill äter.` → ✓ `Jag vill äta.` (After a helper, use the infinitive.)
- ✗ `Han kan läser.` → ✓ `Han kan läsa.` (Only the helper takes the present form.)
- ✗ `Idag jag vill läsa.` → ✓ `Idag vill jag läsa.` (The helper stays in second place.)

## Summary

- Helpers: `vill`, `kan`, `måste`.
- Pattern: subject + helper + infinitive + object.
- The main verb after a helper is always the infinitive.
- Time first moves only the subject: `Idag vill jag läsa.`
