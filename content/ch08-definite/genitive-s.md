# The genitive -s

Swedish shows ownership by adding `-s` to the owner. There is never an apostrophe.

- `Marias bil.` (Maria's car)
- `Eriks hus.` (Erik's house)

## People and names

Add `-s` to the name, then the thing owned. The thing itself stays indefinite.

- `Marias bil.`
- `Annas bok.`
- `Eriks hund.`

Names already ending in `-s` add nothing extra.

- `Anders bil.` (the car of Anders)
- `Hans hus.` (the house of Hans)

## Plurals and definite owners

Definite nouns take `-s` too.

- `barnens rum` (the children's room)
- `hundens mat` (the dog's food)
- `flickans bok` (the girl's book)

## No apostrophe — ever

English writes `Maria's`. Swedish writes `Marias`.

- `Marias bil.` (not `Maria's bil`)
- `barnens rum` (not `barnen's rum`)

## Common mistakes

- ✗ `Maria's bil.` → ✓ `Marias bil.` (Swedish never uses an apostrophe.)
- ✗ `barnens rummet` → ✓ `barnens rum.` (After an `-s` owner, the thing stays indefinite.)
- ✗ `Anderss bil.` → ✓ `Anders bil.` (Names ending in `-s` add nothing.)

## Summary

- Add `-s` to the owner: `Marias bil.`
- Never write an apostrophe.
- Definite owners work too: `barnens rum`.
- Names ending in `-s` stay as they are.
