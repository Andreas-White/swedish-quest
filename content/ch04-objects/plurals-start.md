# Plurals start

English adds "s" for many. Swedish has three common endings: `or`, `ar`, `er`. For now, recognise them. You do not need to produce them all.

## Group 1: -or for many -a words

En-words ending in `a` usually add `or`.

- `en flicka` → `två flickor` (two girls)
- `en klocka` → `två klockor` (two clocks)
- `en kvinna` → `två kvinnor` (two women)

Spot the `or`. You already know these nouns are en-words.

## Group 2: -ar for many en-words

Many other en-words add `ar`.

- `en bil` → `två bilar` (two cars)
- `en tidning` → `två tidningar` (two newspapers)
- `en smörgås` → `två smörgåsar` (two sandwiches)

## Group 3: -er and no change

Many remaining nouns add `er`.

- `en bok` → `två böcker` (two books — vowel changes too)
- `ett äpple` → `två äpplen` (two apples)
- `ett barn` → `två barn` (two children — no change)

Some short ett-words stay the same in plural:

- `ett hus` → `två hus` (two houses)

For now: if you see `hus` after `två`, it is plural by context.

## Common mistakes

- ✗ `två flickar` → ✓ `två flickor.` (Words in `a` take `or`.)
- ✗ `två biler` → ✓ `två bilar.` (`Bil` takes `ar`.)
- ✗ `två huses` → ✓ `två hus.` (`Hus` does not change.)

## Summary

- `-a` words → `or`: `flickor`.
- Many en-words → `ar`: `bilar`.
- Rest → `er` or no change: `böcker`, `hus`.
- Receptive goal: recognise, do not memorise every plural yet.
