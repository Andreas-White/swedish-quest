# The V2 rule

In Swedish the verb always stands in **second place**. Normally the subject is first, so it looks like English. But when something else comes first, the subject moves after the verb.

- `Jag äter.` (`Jag` = 1st, `äter` = 2nd)
- `Du läser.` (`Du` = 1st, `läser` = 2nd)

## Time first: flip subject and verb

When a time word like `idag` (today) or `imorgon` (tomorrow) comes first, it takes place 1. The verb stays in place 2, so the subject moves to place 3.

- `Jag äter frukost.` → `Idag äter jag frukost.`
- `Jag bor på hotell.` → `Imorgon bor jag på hotell.`
- `Hon läser en bok.` → `Idag läser hon en bok.`

Count the places: `Idag` = 1st, `äter` = 2nd, `jag` = 3rd.

## More time words that trigger inversion

- `idag` = today
- `imorgon` = tomorrow
- `igår` = yesterday
- `nu` = now

Each one works the same way.

- `Nu äter jag.`
- `Igår läste vi en bok.`
- `Imorgon kommer han.`

## The verb is always second — never third

The rule never breaks. Only **one** thing goes before the verb.

- `Idag äter jag.` (`äter` is 2nd)
- `Imorgon bor du här.` (`bor` is 2nd)

## Common mistakes

- ✗ `Idag jag äter.` → ✓ `Idag äter jag.` (The verb must be 2nd; the subject moves after it.)
- ✗ `Imorgon jag bor här.` → ✓ `Imorgon bor jag här.` (`bor` stays in 2nd place.)
- ✗ `Nu jag läser.` → ✓ `Nu läser jag.` (Only one word goes before the verb.)

## Summary

- The verb is always in second place.
- Time first means inversion: `Idag äter jag.`
- `idag`, `imorgon`, `igår` and `nu` all trigger the flip.
- Only one element comes before the verb.
