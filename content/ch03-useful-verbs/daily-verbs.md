# Daily verbs

These seven verbs cover most of your day. Each one shows infinitive → present.

- `äta` → `äter` (eat)
- `dricka` → `dricker` (drink)
- `sova` → `sover` (sleep)
- `läsa` → `läser` (read)
- `skriva` → `skriver` (write)
- `köpa` → `köper` (buy)
- `göra` → `gör` (do / make)

One present form for everyone: `Jag äter.` `Hon äter.` `De äter.`

## Morning to evening

- `Jag äter frukost.` (I eat breakfast.)
- `Jag dricker kaffe.` (I drink coffee.)
- `Jag läser en bok.` (I read a book.)
- `Jag skriver ett brev.` (I write a letter.)
- `Jag köper mjölk.` (I buy milk.)
- `Jag sover gott.` (I sleep well.)
- `Jag gör kaffe.` (I make coffee.)

`Göra` is handy. It means both do and make.

- `Vad gör du?` (What are you doing?)

## Spot the pattern

Many verbs add `er` in the present:

- `läser`, `skriver`, `dricker`, `köper`, `sover`

Three are shorter — learn them whole:

- `äter`, `gör`, `läser`

Say them aloud: `äter`, `dricker`, `sover`, `läser`, `skriver`, `köper`, `gör`.

## Common mistakes

- ✗ `Jag ätar frukost.` → ✓ `Jag äter frukost.` (`Äta` is irregular.)
- ✗ `Hon köpa mjölk.` → ✓ `Hon köper mjölk.` (Statements need the present.)
- ✗ `De görar kaffe.` → ✓ `De gör kaffe.` (`Göra` → `gör`.)

## Summary

- `äter`, `dricker`, `sover`, `läser`, `skriver`, `köper`, `gör`.
- Same form for all subjects.
- `Vad gör du?` starts many chats.
