# Modals: vill, kan, måste, bör, får

Modal verbs carry the time of the sentence. The main verb after them stays in the infinitive.

- `Jag vill resa.`
- `Hon kan simma bra.`
- `Vi måste gå nu.`

## Each modal

- `vill` (want to): `Jag vill äta nu.`
- `kan` (can): `Du kan ringa mig.`
- `måste` (must): `Han måste arbeta idag.`
- `bör` (should): `Ni bör vila lite.`
- `får` (may, allowed to): `Vi får sitta här.`

## Permission with Får jag…?

Use `Får jag` + infinitive to ask for permission politely.

- `Får jag fråga något?`
- `Får jag sitta här?`
- `Får jag gå nu?`

Answer by repeating `får`.

- `Ja, du får fråga.`
- `Nej, du får inte röka här.`

## Common mistakes

- ✗ `Jag vill äter.` → ✓ `Jag vill äta.` (After `vill`, use the infinitive.)
- ✗ `Han måste går.` → ✓ `Han måste gå.` (After `måste`, use the infinitive.)
- ✗ `Får jag jag fråga?` → ✓ `Får jag fråga?` (Only one subject after `Får`.)

## Summary

- Modals take the infinitive: `Du kan ringa mig.`
- `vill`, `kan`, `måste`, `bör` and `får` all follow this pattern.
- Ask permission with `Får jag` + infinitive.
